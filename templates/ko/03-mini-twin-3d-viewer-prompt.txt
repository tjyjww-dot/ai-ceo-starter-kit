『나는 AI를 사장으로 고용했다』 부록 E, 템플릿 ③의 두 번째 파일(14장용).

사용법
  1. 이 파일과 03-미니트윈-상태파일-예시.json을 같은 폴더에 둡니다.
  2. 아래 점선 두 줄 사이의 내용을 전부 복사합니다.
  3. 그 폴더에서 실행 중인 클로드에게 붙여넣습니다.
  4. 클로드가 만들어 준 HTML 파일을 더블클릭합니다. 브라우저에 3D 오피스가 열립니다.

붙여넣기 전에 아래 내용을 고칠 필요는 없습니다. 만약 JSON 파일 이름을 바꿨다면,
아래 첫 줄의 파일명만 그에 맞게 바꾸세요.

------------------------------------------------------------------------------
이 폴더에 있는 03-미니트윈-상태파일-예시.json 파일을 읽어서, 그 내용을 작은
3D 오피스로 보여주는 단일 웹페이지 하나를 만들어 줘.

"departments"의 각 항목마다 사람 모양 아바타를 하나씩, 자기 책상 앞에 세워 줘.
그리고 status에 따라 아바타 색을 다르게 칠해 줘: normal은 초록색, warning은
빨간색, dormant는 회색. 각 아바타 위에 부서 이름표를 달고, 내가 아바타에
마우스를 올리면 그 "note" 텍스트가 보이게 해 줘.

Three.js를 써 줘. 내가 서버 없이, 인터넷 연결 없이, 내 컴퓨터에서 HTML 파일을
직접 더블클릭해서 열었을 때 전부 동작해야 하니까 모든 걸 한 파일 안에 인라인으로
넣어 줘. 브라우저에서 JSON을 그렇게 읽을 수 없으면, JSON 내용을 페이지 안에 직접
박아 넣고, 상태가 바뀔 때 어느 줄을 고쳐야 하는지 알려주는 주석을 달아 줘.

맨 아래에 "updated_at" 값을 표시하는 줄을 하나 넣어 줘. 내가 지금 보고 있는 게
얼마나 오래된 정보인지 항상 알 수 있게.
------------------------------------------------------------------------------

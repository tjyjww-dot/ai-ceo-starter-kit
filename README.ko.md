# AI CEO 스타터 킷

AI에게 **실제로 반복되는 일**을 맡기기 위한 시작 파일들과, 그게 사고로 이어지지 않게 막는 안전
규칙입니다. 직원이 전부 AI인 1인 회사에서 실제로 쓰는 것들을 꺼냈습니다.

**그 회사가 지금 돌아가는 걸 가입 없이 바로 보실 수 있습니다: [twin.quantlabnote.com/guest](https://twin.quantlabnote.com/guest)**

라이브 3D 오피스입니다. 책상 하나하나가 실제로 도는 부서예요 — 매일 유튜브 쇼츠를 만들어 올리는
봇, 매일 아침 블로그에 글을 발행하는 봇, 증권사 API로 실제 주문을 넣는 봇 둘, 그리고 새벽 2시
30분부터 이 오피스의 3D 코드 자체를 고쳐 쓰는 야간조. 말풍선은 그 직원이 방금 진짜로 한 일입니다.
연출한 화면이 하나도 없습니다.

## 여기서 시작하세요: 이 파일 하나를 AI에게 건네주세요

```
give-this-to-your-ai.ko.md
```

열어서 통째로 복사한 다음, 쓰시는 AI(클로드·챗지피티 등)에 붙여넣으세요. 준비는 그게 전부입니다.
AI가 그걸 읽고 나면, 빈 폴더에서 **사람 없이 스케줄대로 도는 회사**까지 단계별로 안내하는 가이드가
됩니다. 그리고 더 중요한 건, **여러분이 밀어붙여도 AI가 지키는 다섯 개의 안전 게이트**가 그 안에
박혀 있다는 점입니다.

| 게이트 | 여러분이 시켜도 AI가 거부하는 것 |
|---|---|
| **1** | 모의투자 한 달과 검증 통과 전에 실제 돈을 건드리는 것 |
| **2** | API 키·토큰·비밀번호를 그냥 파일에 적어 두는 것 |
| **3** | 삭제·발송·게시·결제를 그 건에 대한 사람의 "예" 없이 실행하는 것 |
| **4** | 투자 자문을 하거나, 그걸 파는 걸 돕는 것 |
| **5** | 작고 되돌릴 수 있는 방법이 있는데 크고 영리하고 되돌릴 수 없는 변경을 하는 것 |

게이트 1이 있는 이유는 이 회사가 실계좌를 돌리기 때문이고, 게이트 3이 있는 이유는 스케줄대로 기계
속도로 글을 올리는 봇이 계정 정지를 부르기 때문입니다 — 저희가 한 번 당했습니다. 가정이 아니라
전부 실제로 겪은 일입니다.

## 무엇이 들어 있나

전부 **완성품이 아니라 출발점**입니다. 그대로 쓰셔도 되고, 하나를 AI에게 통째로 보여주면서 "내
상황에 맞게 고쳐줘"라고 하셔도 됩니다.

| 파일 | 무엇에 쓰는가 |
|---|---|
| [`templates/ko/01-mini-company-constitution-CLAUDE.md`](templates/ko/01-mini-company-constitution-CLAUDE.md) | AI가 무엇을 해도 되고 안 되는지 적은 평범한 텍스트 파일 하나. 프로젝트 폴더에 **`CLAUDE.md`** 라는 정확한 이름(대소문자 포함)으로 저장 |
| [`templates/ko/02-morning-briefing-bot-skeleton.py`](templates/ko/02-morning-briefing-bot-skeleton.py) | 첫 AI 직원: 매일 아침 정해진 시각에 사람 없이 브리핑하는 봇. `PASTE_HERE` 두 곳만 채우면 됩니다 |
| [`templates/ko/03-mini-twin-status-file-example.json`](templates/ko/03-mini-twin-status-file-example.json) + [`03-mini-twin-3d-viewer-prompt.txt`](templates/ko/03-mini-twin-3d-viewer-prompt.txt) | 위 링크의 3D 관제실 축소판. 부서 셋을 여러분이 가진 진짜 셋으로 바꾸고, 프롬프트는 그대로 AI에게 건네세요. **두 파일은 붙여서 쓰세요** |
| [`templates/ko/04-12-month-roadmap-checklist.md`](templates/ko/04-12-month-roadmap-checklist.md) | 항목마다 **"접는 조건"**이 적힌 12개월 로드맵 |

> 원본 파일명은 한글이었지만(책 부록 E 기준), GitHub 주소에서 깨져 보여서 영문으로 바꿨습니다.
> 번호와 순서는 책과 같으니 그대로 대응됩니다. 영문판은 [`templates/en/`](templates/en/)에 있습니다.

## 아무리 고쳐 쓰더라도 굽히면 안 되는 두 가지

1. **시크릿을 보관하는 파일에 직접 적지 마세요.** `PASTE_HERE` 같은 자리가 있다는 건, 그걸 채우는
   순간 그 파일이 비밀을 품게 된다는 뜻입니다. `.env`로 옮기고 Git에서 제외하세요.
2. **막히면 화면을 그대로 AI에게 보여주세요.** 이 템플릿들은 여러분과 AI가 같이 고쳐 쓰는 걸
   전제로 만들었습니다. 혼자 정답을 맞힐 필요가 없습니다.
